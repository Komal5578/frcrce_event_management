## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/server action to lib/domain | Untrusted ids and values; actor comes from the session, never from the request |
| lib/domain to D1 | All SQL parameterised |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08-01 | Elevation | Missing RLS replacement lets a student read or write events | mitigate | Role/ownership in every WHERE clause plus requireActorRole; authz tests for each role pair; boundary test so routes cannot bypass lib/domain |
| T-03-08-02 | Elevation | Self-promotion to admin or self-approval | mitigate | No function updates profiles.role; reviewEvent admin-only; test asserts export list and self-approve rejection |
| T-03-08-03 | Tampering | SQL injection | mitigate | bind() only; grep test for interpolated SQL |
| T-03-08-04 | Information disclosure | SQL or constraint text leaked in error messages | mitigate | humanize() maps to fixed sentences; test asserts no SQL words |
| T-03-08-05 | Tampering | Read-then-write races on seats and ownership | mitigate | Single-statement upsert and WHERE ownership; DB backstop triggers |
| T-03-08-06 | Denial of service | More than 50 D1 queries per invocation (free tier) | mitigate | Join/aggregate list queries; note in HANDOFF |
</threat_model>
