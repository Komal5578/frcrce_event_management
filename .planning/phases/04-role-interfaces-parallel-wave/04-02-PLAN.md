<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> server action | public POST endpoint; event/task ids and labels are untrusted |
| server action -> lib/domain | actor derived from the session only |
| student UI -> other users' data | counts only; no registrant lists or names |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-21 | Spoofing | register/cancel/task actions | mitigate | `requireRole("student")` in every action and page; actor `{id, role}` from the session; tests mock the session |
| T-04-22 | Elevation of privilege | IDOR on event and task ids | mitigate | registerForEvent/cancelRegistration use actor.id in SQL; setTaskStatus checks assignee; hidden events give NOT_ALLOWED via getEventDetail; tests assert the not-assignee message |
| T-04-23 | Tampering | double registration / last seat race | mitigate | single-statement registerForEvent + UNIQUE + capacity trigger; UI additionally hides Register for registered students |
| T-04-24 | Information disclosure | other registrants, raw DB errors | mitigate | views return counts and own `my_reg` only; only DomainError.message or the generic sentence shown |
| T-04-25 | Tampering (XSS) | event titles/descriptions | mitigate | React escaping; no dangerouslySetInnerHTML; ConfirmDialog takes children |
| T-04-26 | Tampering | filter/search params | mitigate | params are parsed and applied in TypeScript only, never placed in SQL (SQL is constant in lib/domain) |
| T-04-SC | Tampering | npm installs | accept | no package installed; AGENTS.md forbids new dependencies |
</threat_model>
