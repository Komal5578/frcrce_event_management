<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> server action | public POST endpoint; every field and id is untrusted |
| server action -> lib/domain | actor is derived from the session, never from the request |
| route code -> database | forbidden; only lib/domain and lib/auth may be imported |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Spoofing | coordinator actions | mitigate | `requireRole("coordinator")` at the start of every action and page; actor `{id, role}` from the result; tests mock the session and assert an other-coordinator event id yields NOT_ALLOWED |
| T-04-12 | Elevation of privilege | IDOR on event/task ids | mitigate | domain WHERE clauses include coordinator_id; tests assert rejection; no client-supplied user id accepted |
| T-04-13 | Tampering | mass assignment via form | mitigate | `_lib/parse.ts` whitelists fields; status/coordinator_id/return_reason never read from input |
| T-04-14 | Tampering | clash/overbooking race | mitigate | DB triggers remain the guarantee; UI pre-filters with freeVenues/resourceAvailable and shows DomainError text |
| T-04-15 | Information disclosure | registrant identities, raw DB errors | mitigate | counts only via seatCounts/EventView; only DomainError.message or the generic sentence is shown |
| T-04-16 | Tampering (XSS) | titles, descriptions, reasons | mitigate | React escaping only; no dangerouslySetInnerHTML; ConfirmDialog receives children not HTML |
| T-04-17 | Tampering | CSRF on actions | accept | Next.js Server Actions enforce same-origin; no custom state-changing GET routes (GET forms only filter/show) |
| T-04-SC | Tampering | npm installs | accept | no package installed in this plan; AGENTS.md forbids new dependencies |
</threat_model>
