Conventions fixed for this whole plan (from RESEARCH "Instrument conventions"; the plan 03 check script parses exactly this):
- Frontmatter on every docs file, one key per line: `id` (prefix `doc-research-`), `type: research-instrument`, `title`, `tags`, `confidence: assumed`, `sources`, `summary`, `updated: 2026-10-20`.
- Banner directly under the H1 of every file: "AI-drafted instrument. This file contains no responses, quotes or findings. Only the team may record results, and only real sessions may be marked evidence."
- Question line format: each question is a Markdown bullet: `- ` prefix, then the id, then the question text, then the tag list at the END of the same line, for example `- Q-C03. <question text> [P1, P6]`. Nothing but the bullet marker (`- ` or `* `) may precede the id on that line. Interview ids are `Q-C##`, `Q-S##`, `Q-A##`; questionnaire ids are `QN-C##`, `QN-S##`, `QN-A##`. Ids unique within a file, two digits, numbered continuously within each section. Tags only P1..P10. Probes go on the next line as an indented sub-bullet starting `  - Probes:`. Questionnaire response options go on the next line as an indented sub-bullet starting `  - Options:`. Leave a blank line between question blocks so the Markdown renders readably. The parser pattern is `^[-* ]*(QN?-[CSA]\d{2})\.`.
- Section headings (exact pattern, level 2): `## Section A: Coordinators`, `## Section B: Students (including Organizers)`, `## Section C: Admins`. No other level-2 heading may contain the words Coordinator, Student or Admin.
- P# is the item number in `dom-hmi-problems` (P1 = item 1 ... P10 = item 10).
- Forbidden words/patterns in these files: the two words the project scope excludes (`attendance`, `shortage`), email/SMS/payment questions (`adr-004-scope`), `participant <digit>`, `respondent <digit>`, `quote:`, `findings:`, `n=<digit>`, digit-percent figures, any invented answer, sample response or illustrative quote.
- Organizer is a variant inside Section B, not a fourth section (`adr-002-roles`).
- No emojis.
