## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-01 | Tampering | lib/csv.ts toCsv | mitigate | Leading `'` for cells starting `= + - @ \t \r`, quote doubling, tested in csv.test.ts |
| T-05-02 | Information disclosure | buildReport scope | mitigate | `requireActorRole` coordinator/admin; actor-scoped `listEventsWithSeats`; test that coordinator B sees none of A's events |
| T-05-03 | Information disclosure | report content | mitigate | Counts only; no registrant name/email columns; test asserts column keys |
| T-05-04 | Tampering | filters | mitigate | `parseFilters` whitelists status keys and ISO dates; SQL only constant strings with bound params (db-boundary test) |
| T-05-05 | Elevation of privilege | computeAlerts | mitigate | Role filter inside computeAlerts (student never gets clash/lowreg) |
| T-05-SC | Tampering | npm installs | accept | No packages installed in this plan |
