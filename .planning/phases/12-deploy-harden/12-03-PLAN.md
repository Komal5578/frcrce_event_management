<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet to EC2 | Caddy is the only public app ingress; SSH is IP-restricted. |
| Containers to Postgres | API and Postgres communicate on the private Compose network. |
| EC2 to S3 | Backup uses temporary instance-role credentials scoped to one bucket. |
| Browser/Vercel to API | Same-origin rewrite forwards the session; FastAPI domain checks authorization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Information disclosure | Compose ingress and environment | mitigate | Keep database/API private and secrets out of tracked files. |
| T-12-02 | Elevation of privilege | EC2 to S3 | mitigate | Scope the instance role to the configured bucket; no static keys. |
| T-12-03 | Denial of service/data loss | Postgres backup | mitigate | Verify scheduled dumps and restore before accepting deployment. |
| T-12-10 | Spoofing | Session cookie/rewrite | mitigate | Verify production cookie attributes and actual authenticated proxy request. |
</threat_model>
