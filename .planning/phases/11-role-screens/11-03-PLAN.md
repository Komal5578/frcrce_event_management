## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin browser/server action to FastAPI | Event/catalog ids, decisions, return reasons, and resource values are untrusted; cookie is server-managed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-07 | Elevation of privilege | Admin actions and API | mitigate | Preserve backend `require_roles` and domain authorization; route visibility is not security. |
| T-11-08 | Tampering | Approval and catalog forms | mitigate | Validate at FastAPI/schema/domain boundaries and preserve Postgres clash/resource constraints. |
| T-11-09 | Repudiation | Approval decisions | mitigate | Submit through existing authenticated API/domain path and display resulting state and return reason. |
| T-11-10 | Information disclosure | API session handling | mitigate | Keep httpOnly cookie forwarding on the server and do not expose tokens to browser code. |
</threat_model>
