| T-11-01 | Elevation of privilege | Student actions and API | mitigate | Keep server route guards for UX and rely on `current_actor`/`require_roles` and domain authorization for every write. |

| T-11-03 | Information disclosure | API session handling | mitigate | Forward the httpOnly session only through the Phase 10 server-side API client; never expose session tokens to client JavaScript. |
</threat_model>
