<task id="10-03-01">
<name>Fix navigation matching logic & test active state</name>
<instruction>
Refactor active route detection in `frontend/components/ui/app-shell.tsx`:
1. Extract helper `isNavActive(pathname: string, href: string): boolean`.
2. For root role paths (`/coordinator`, `/admin`, `/student`), require exact match `pathname === href`.
3. For nested section paths (e.g. `/coordinator/events`), allow prefix matching `pathname === href || pathname.startsWith(href + "/")`.
4. Create `frontend/tests/app-shell.test.ts` testing that `/coordinator` is NOT marked current when viewing `/coordinator/new` or `/coordinator/calendar`.
</instruction>
<verification>
Run `cd frontend && npx vitest run tests/app-shell.test.ts` to verify the navigation matcher logic.
</verification>
</task>

<instruction>
Update `frontend/components/ui/app-shell.tsx`:
1. On desktop (`lg:block`), keep the fixed left sidebar.

<task id="10-03-03">
<name>Build StudentShell with mobile bottom tab bar</name>
<instruction>
Create `frontend/components/ui/student-shell.tsx`:
1. On desktop (`lg:block`), provide the left sidebar navigation.
2. On mobile (`< 1024px`):
   - Fixed bottom tab bar (`h-16 border-t border-border-card bg-surface z-40`) with 4 primary targets:
     - Discover (`Compass` / `Search`)
     - My Events (`Calendar` / `Ticket`)
     - Tasks (`CheckSquare`, conditionally shown if organizer has assigned tasks)
     - Notifications (`Bell`, showing unread badge indicator)
   - Ensure touch target sizes are at least 44x44px.
   - Main content has bottom padding (`pb-20`) on mobile to prevent content occlusion.
3. Wire into `frontend/app/(student)/layout.tsx`.
</instruction>
