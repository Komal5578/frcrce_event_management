<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/proxy -> routers | all path, query and body input is untrusted |
| role -> endpoint | cross-role access must be denied server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-24 | Elevation | any route missing a role check | mitigate | `require_roles` per route plus domain `require_actor_role`; route-matrix test iterates all routes |
| T-09-25 | Elevation | CSV export open to students | mitigate | dependency + domain check; explicit student 403 test |
| T-09-26 | Tampering | mass assignment via bodies | mitigate | Pydantic `extra="forbid"`, PATCH whitelists, actor never in body |
| T-09-27 | Tampering | oversized/malformed input | mitigate | length limits, AwareDatetime, enum Literals; 422 on violation |
| T-09-28 | Info disclosure | OpenAPI/docs exposure | accept | demo project; Phase 12 may disable /docs via env |
| T-09-29 | Info disclosure | error leakage | mitigate | only `{code,message}` human texts; psycopg errors translated, no SQL in responses |
| T-09-30 | Elevation | demo login enabled in prod compose | mitigate | compose dev sets DEMO_LOGIN=true only; `.env.example` default false; Phase 12 prod env |
</threat_model>
