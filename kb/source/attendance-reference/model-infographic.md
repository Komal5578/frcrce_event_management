# Infographic layout (design-model.png)

One-page poster: title + 4 value badges (Accurate, Fast, Transparent, Secure). Left column: the 7 GDD steps in coloured boxes, then 3 user personas (name, role, goal, pain point). Centre: faculty workflow strip (Login → Today's Schedule → Start → Verify → Review & Correct → Submit → Summary) over real screens (schedule, mark attendance, review & confirm donut chart, submitted confirmation). Below: student mobile screens (4 phones: dashboard with overall ring, subject-wise bars, subject detail, alerts) and the administrator dashboard (KPI tiles, trend line, department pie, shortage list). Footer: key features, HMI principles applied (icon per principle), and a status-colour legend (Present/Absent/Late/Excused).

Use as the template for our final one-page design model (phase 7). Image: `design-model.png`.
