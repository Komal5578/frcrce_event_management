# Minimum deliverables

Objective (original): design and prototype a user-centred system using the GDD process; conduct user research, develop personas, identify goals, define requirements, design interaction flows and wireframes, build a high-fidelity prototype, and run usability testing with representative users.

1. User research
2. User personas
3. User goals and task analysis
4. User scenarios
5. Requirements
6. Information architecture
7. User/task flow
8. Low-fidelity wireframes
9. High-fidelity interactive prototype
10. Usability testing
11. Usability findings
12. Iterative design improvements
13. Final prototype

Mapping of each deliverable to a GSD phase lives in `dom-deliverable-map`.
