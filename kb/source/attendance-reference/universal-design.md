# Universal Design principles

| Principle | Application | Evaluation question |
|-----------|-------------|---------------------|
| Equitable use | Every role (incl. users with accessibility needs) can do their task | Can different users accomplish their task without being unnecessarily excluded? |
| Flexibility in use | Alternatives: QR/automated + manual; different devices | Are there alternatives for different preferences or circumstances? |
| Simple and intuitive use | No manual needed; student dashboard shows overall % at once | Can a first-time user understand and complete the task? |
| Perceptible information | Never colour alone: icon + text + chart + status + feedback ("🔴 Absent" or "Absent – 7") | Can users understand it even if they can't perceive one visual characteristic (e.g. colour-blind)? |
| Tolerance for error | Review → Confirm & Submit; "Are you sure?" with Yes/Cancel | Does it prevent serious errors and make recovery easy? |
| Low physical effort | Use the timetable: Today's Schedule → Subject → Class → Start (not 6 selections each time) | Can frequent tasks be done with minimum unnecessary interaction? |
| Size and space | Adequate target size/spacing; Confirm & Submit clearly distinguishable from Cancel; applies to nav, controls, search, filters, alerts | (touch-target and separation check) |
